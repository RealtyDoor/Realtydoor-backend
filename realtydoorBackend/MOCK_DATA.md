# Mock QA data — every state, for frontend integration

Generated by `node scripts/seedMockStates.js` against this environment's
database. It covers every status, edge case and derived state introduced by
this session's commits — the ones listed in `API.md` under: listing change
requests, exclusive mandates & conflicts, location check, mortgage/NOC,
listing visibility & requested changes, the persona checklist & owner
confirmation, KYC document requests, escrow freeze, data acknowledgments, and
auto-assign.

**Nothing here is real data.** Every user is `*@mockqa.test`, every property
title starts with `MOCK QA —`, every mock lead's `refCode` starts with
`L-MOCKQA`. Safe to delete, safe to ignore, never touches a real record.

**Every fixture was built by calling the real service function** (not by
inserting rows by hand), so what you see through the API is exactly what a
real partner/admin action would produce — not an approximation.

Re-running the script is a no-op once seeded (it checks for
`mockqa.owner.verified@mockqa.test` and exits if found). To regenerate, delete
everything matching `@mockqa.test` / `MOCK QA` first.

The exact ids below are also in `scripts/.mockStatesIndex.json` (gitignored —
regenerate it by re-running the script after a reseed).
